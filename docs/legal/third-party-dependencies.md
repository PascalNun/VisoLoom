No image-processing library is selected: first passthrough service returns encoded bytes. A future resampler/PNG decoder outside Rhino requires a separate license/native-architecture review. Do not introduce standalone `System.Drawing.Common` as a Mac solution. No Python, FastAPI, ComfyUI, PyTorch, CUDA, MLX, FLUX weights, cloud SDKs, or copied upstream sample code is part of this project.

For a future local pipeline, inventory runtime code, model weights, text/image encoders, tokenizer, preprocessing/control networks and upscalers separately. “FLUX” is a family, not a single license. Downloadability or an “open weights” label does not establish commercial use or redistribution rights. Do not add GPL/AGPL or similarly consequential components without approval; LGPL and conditional/custom licenses need case-specific evaluation.

Release checklist: pin exact artifacts; enumerate transitives and native assets; read their license and NOTICE files; document what is actually shipped; preserve required notices; check abandonment/security exposure; review provider service terms separately. The checklist does not choose VisoLoom's own license.
