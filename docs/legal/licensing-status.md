# Licensing and distribution status

**Decided 21 November 2026: VisoLoom's source is licensed under GPL-3.0-or-later.** The repository's root `LICENSE` carries the GNU GPL Version 3 text; the "or any later version" option follows the copyright holder's designation in this file and the README. The analysis and the recorded direction are in the [software licence decision memo](software-licence-decision.md).

The licence governs the repository source only. Model weights keep their publishers' terms (Apache-2.0, FLUX Kommunity and others) and are never committed or bundled; future bundled native runners carry their own artifact-level review ([engine productization plan](../development/engine-productization-plan.md)); brand assets and future Library assets carry their own per-asset rights records.

The GitHub repository is **public** at [PascalNun/VisoLoom](https://github.com/PascalNun/VisoLoom) since 21 November 2026, with its complete history — scanned for secrets before publication, none found. Yak packages, packaged binary releases and any distribution remain gated on an explicit go-ahead. Dependency licenses and service/model terms are separate from VisoLoom's own licence. Keep an exact version inventory and required notices before distributing any binary — see the [resolved dependency inventory](third-party-dependencies.md). Do not infer rights to weights, training assets or third-party textures from the availability of API access or readable source.
